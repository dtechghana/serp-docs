Library
#######

The Library module allows you to manage the school's book collection — including cataloguing books by category, tracking the book inventory, and recording book issues and returns.

Access the Library module from **Library** in the main navigation menu.

.. |edit_icon| image:: ../images/pencil.png
.. |delete_icon| image:: ../images/trash.png


.. _library_categories:

Book Categories
***************

Book categories are used to organise books in the library catalogue. Requires the **Library (Categories)** access role (role 28).

Navigate to **Library > Book Categories** to manage categories.

**Adding a Category**

1. From the "Add Category" pane, enter the category name
2. Click **Add Category**

**Deleting a Category**

From the category list, click the delete (|delete_icon|) button for the category you wish to remove and confirm.

.. warning::
	Deleting a category that has books assigned to it is not recommended and may affect book records.


.. _library_books:

Books
*****

The Books section is the main catalogue of all books in the library. Requires the **Library (Books)** access role (role 29).

Navigate to **Library > Books** to manage books.

**Adding a Book**

1. From the "Add Book" pane, enter the following:

	* **Book Category**: select the category this book belongs to
	* **Title**: the full title of the book
	* **Author**: the author(s) of the book
	* **ISBN**: the book's ISBN (optional)
	* **Quantity**: number of copies available

2. Click **Add Book**

**Editing a Book**

Click the edit (|edit_icon|) icon next to the book you wish to update, make your changes, and save.

**Deleting a Book**

Click the delete (|delete_icon|) icon next to the book you wish to remove and confirm.


.. _library_issue:

Issuing a Book
**************

Navigate to **Library > Issue Book** to record a book being issued to a student or staff member.

The issue book view displays a list of all currently issued books, including the borrower, issue date, and expected return date.

**Recording an Issue**

1. Search for the book by title or ISBN
2. Select the borrower (student or staff)
3. Enter the issue date and expected return date
4. Confirm the issue


.. _library_return:

Returning a Book
****************

Navigate to **Library > Book Return** to record a book being returned.

Search for the issued record by borrower name or book title, then confirm the return.


.. _library_findbook:

Finding a Book
**************

Navigate to **Library > Find Book** to search the catalogue by title, author, ISBN, or category.


.. _library_reports:

Library Reports
***************

Navigate to **Library > Reports** to view library usage reports, including issued books, overdue returns, and book inventory summaries.
