sERP Mobile App
#################

.. note::

   This feature is available in **sERP v2**.

The sERP Mobile App is a free, native app for parents and students, available on Android and iOS. It provides the same information as the web-based :doc:`/manage/parentportal` and :doc:`/manage/studentportal`, with push notifications and a dedicated mobile interface.

.. note::

   The mobile app is a separate download from the school's own sERP installation — it works against any school's sERP install, resolved once during onboarding (see below), not tied to a specific school at install time.


.. _mobile_app_onboarding:

Getting Started
******************

The first time the app is opened, it asks for a **school code** — a 6-digit code unique to the school's own sERP installation. Contact the school (or your account manager, if setting this up for a school) for the code.

Once entered, the app connects to that school's installation and shows the normal sign-in screen — the same username and password used for the web Parent Portal or Student Portal.

If the wrong code was entered, or the app needs to be pointed at a different school, use **Not your school? Change code** on the sign-in screen.


.. _mobile_app_features:

What's Available
*******************

For a student account, the app provides:

* Fees and payment history (see :ref:`studentportal_fees`)
* Assignments, including submission where supported (see :ref:`studentportal_assignments`)
* Timetable
* Attendance (see :ref:`studentportal_attendance`)
* Report card, once published
* Calendar of school events
* In-app messaging and parent-teacher conference scheduling

For a parent/guardian account, the same information is available per ward, plus switching between wards without signing in again if more than one child is enrolled at the school.

Push notifications alert a parent or student to new messages and other updates without needing the app open.


.. _mobile_app_wards:

Multiple Children, One Login
*********************************

A parent with more than one child at the same school signs in once and switches between wards from within the app — the same account used for all of them, matching the web Parent Portal's existing behaviour.
