Parent Portal
#############

The Parent Portal provides parents and guardians with a dedicated interface to monitor their children's academic progress, fees, attendance, and school communications — without requiring access to the full administration panel.

.. note::

	Access to the Parent Portal requires a **Guardian** user account. See :ref:`users_add_user` for instructions on creating parent/guardian accounts and linking them to students.

The Parent Portal is accessed at ``/parentportal`` on your sERP installation.

.. |edit_icon| image:: ../images/pencil.png


.. _parentportal_dashboard:

Dashboard
*********

The Parent Portal dashboard provides an overview of all linked wards, including:

* Each ward's current class
* Outstanding fees balance across all wards
* Quick links to each ward's individual details

If a parent has more than one child registered in sERP, all wards are displayed together on the dashboard.


.. _parentportal_students:

My Wards
********

Navigate to **My Wards** to view a list of all children linked to the parent account. Click on a ward's name to view their individual profile, which includes personal details, class, and academic information.


.. _parentportal_fees:

Fees & Billing
**************

Navigate to **Finance > Fees** to view the current term's fees for a ward. This shows:

* Itemised bill
* Amount paid
* Outstanding balance
* Any arrears from previous terms

**Viewing a Bill**

Click **View Bill** to open a printable version of the ward's bill for the current term.

**Fee Payment History**

Navigate to **Finance > Payment History** to see a record of all payments made for a ward across all terms.

**Online Payment**

If online payments are enabled by the school, a **Pay Now** option is available. See :ref:`finance_online_payment` for details on the online payment process.


.. _parentportal_attendance:

Attendance
**********

Navigate to **Attendance** to view the attendance record for a ward. The attendance summary shows:

* Total school days
* Days present
* Days absent
* Attendance percentage

An attendance chart provides a visual breakdown of attendance over the term.


.. _parentportal_assignments:

Assignments
***********

Navigate to **Assignments** to view assignments set for a ward's class. Each assignment shows:

* Subject
* Title and description
* Due date
* Marks (if graded)


.. _parentportal_reports:

Progress Reports
****************

Navigate to **Progress Reports** to view and download a ward's terminal (end-of-term) report. Reports are available once published by the school administration.


.. _parentportal_calendar:

Academic Calendar
*****************

Navigate to **Calendar** to view the school's academic calendar events, including term dates, exams, and school activities.


.. _parentportal_communication:

Communication
*************

Parents can participate in the school's communication features from the portal:

* **Messages**: send and receive direct messages with staff via **Communication > Messages**
* **Conferences**: view scheduled parent-teacher conferences via **Communication > Conferences**
* **Feedback**: submit feedback on teachers and school services via **Communication > Feedback**
* **Forums**: participate in class and school discussion forums via **Communication > Forums**

.. note::

	Access to messaging and forums requires the corresponding communication roles to be assigned by the school administrator. See :ref:`communication_messaging` for details.
